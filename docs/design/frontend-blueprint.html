component strategy

Every page is built in four layers, from the outside in. The colors match the boxes in the anatomy below.

layout: the page shell shell: on every page block: reused inside pages inline: used once, stays in the page
  1. Pages compose, components render.

    index.astro gathers text from i18n/ui.ts and content from lib/, then passes it down as props. UI strings are looked up with useTranslations(lang); content is never looked up inside a component.

  2. The layout owns what every page shares.

    BaseLayout renders the head, fonts, analytics, the column, Header and Footer. Pages only fill its <slot />.

  3. Extract a component when it repeats or has its own behavior.

    Row repeats across five pages. StatusLoop owns an animation and its accessibility rules. The home hero is used once, so it stays inline.

  4. Vary with props and slots, not copies.

    Row has a named meta slot: a date, a label, a StatusLabel or a StatusLoop, with no change to Row.

  5. Same role, same props.

    Row and FeaturedRow both take title, description?, href? and a meta slot. Without href they render a <div>.

  6. Links instead of JavaScript.

    The EN/ES toggle and the tag filter are links to real URLs, marked with aria-current. No script ships for them.

  7. Only link what's built. decided

    lib/routes.ts reads src/pages/**. Nav items, the language toggle and home rows link only to pages that exist, so main never ships a broken link while milestones land one by one. A styled 404 catches anything else.

decisions

// open

  • line-height 1.55 / 1.6 / 1.7Row descriptions, intros and project body in the prototype. The build uses Tailwind's leading-relaxed (1.625) for all three. Recommendation: keep it, because the difference is under half a pixel per line and it saves three tokens.

// decided

  • fontsAstro Fonts API with the Fontsource provider; Geist 400–600 and Geist Mono 400–500, latin, upright only; Geist preloaded.2026-10-01 · recommendation accepted
  • #FFFFFFBecomes --color-white, used for link hover.2026-10-01 · recommendation accepted
  • #7F848ECode comments use --color-muted.2026-10-01 · recommendation accepted
  • 48 → 52MakerLab title uses 5xl, like the other project titles.2026-10-01 · recommendation accepted
  • 18 → 17Post body uses md; the scale stays at ten sizes.2026-10-01 · recommendation accepted
  • 15 → 14Social links on About use sm.2026-10-01 · recommendation accepted
  • togglesThe EN/ES toggle and the tag filter are links, not buttons.2026-10-01 · recommendation accepted
  • shimmerThe StatusLoop shimmer runs on the word cycle, so it never gets cut mid-word.2026-10-01 · reported by Daniel, fix accepted
  • built-only linksNav, toggle and rows link only to pages that exist; a styled 404 catches the rest.2026-10-01 · decided by Daniel
  • videosDeferred until the YouTube channel opens: no videos page, nav item, home row or YouTube link.2026-10-01 · decided by Daniel
  • latest postHidden on home until the first real post ships in M5.2026-10-01 · recommendation accepted
