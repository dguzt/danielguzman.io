# Design reference (read-only)

Approved prototype for danielguzman.io, One Dark theme.

- `prototype/` — one HTML file per page. Open them in a text editor to read layout and inline styles. They depend on a runtime that isn't included, so they won't render standalone; the live prototype is on claude.ai.
- `content/copy.en.json`, `copy.es.json` — all UI copy per page. `[BRACKETS]` = placeholder to fill.
- `assets/profile.jpeg` — current profile photo.

Do not edit. Build the real site in `src/`.
